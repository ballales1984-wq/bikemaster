# BikeMaster

A modern application for bike management and tracking.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/ballales1984-wq/bikemaster.git
cd bikemaster
npm install
```

### Development

```bash
npm run dev
```

### Building

```bash
npm run build
```
