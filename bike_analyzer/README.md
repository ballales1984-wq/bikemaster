# Bike Analyzer

An application to analyze cycling performance data, focusing on energy efficiency, fatigue, and recovery recommendations.

## Features
- Import cycling data (Google Fit or manual)
- Calculate calories burned and energy expenditure
- Analyze fatigue levels and suggest recovery
- Track performance trends over time
- Provide intelligent training recommendations

## Structure

```
bike_analyzer/
├── app/

├── tests/

```

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python run.py`
